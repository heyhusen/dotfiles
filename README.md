This is my personal, customized dotfiles, intended **only as a reference**,
not a drop-in solution.

I use this alongside my
[**lightblue** immutable Linux system](https://github.com/heyhusen/lightblue),
and this repository is managed with
[**chezmoi**](https://github.com/twpayne/chezmoi) for seamless synchronization
and deployment.

> Note for my future self:  
> Don't forget to restore your SSH & GPG key.

## Related Repositories

- [lightblue](https://github.com/heyhusen/lightblue) – My customized immutable
  Linux system powered by Fedora Atomic.
- [chezmoi](https://github.com/twpayne/chezmoi) – The tool in use here to
  streamline dotfile management across machines.
